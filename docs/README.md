# Documentation archive

This folder is the central repository for the project's writing, lore, references, decision records, and historical material.

Use it to preserve the creator's thinking and the long-term context of the project without turning everything into the same kind of document.

## Contents

- `lore/` for worldbuilding and setting material
- `narrative/` for story fragments and narrative direction
- `references/` for inspiration and research documentation
- `decisions/` for explicit creative decisions and revisions
- `history/` for historical context and previous directions

This area should remain clearly archival and should not be confused with active production files.
