# Ideas and experiments

This is the place for the things that are exciting but not ready to become a full project yet.

It’s where the weird, speculative, and half-formed work goes.

## Structure

```text
ideas/
├── README.md
└── projects/
    ├── abandoned-idea/
    ├── future-concept/
    └── strange-experiment/
```

## Good things to put here

- abandoned concepts
- future ideas
- loose world thoughts
- design experiments
- side projects that might turn into something later

## Rule

Ideas still deserve their own space. A rough concept is not the same as a pile of random notes in one folder.
