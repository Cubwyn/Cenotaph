# Games directory

This is the space for game ideas, prototypes, systems, and mechanics.

Some of these may become full projects later. Some may only ever be experiments. That’s fine.

## Structure

```text
games/
├── README.md
└── projects/
    ├── game-one/
    ├── game-two/
    └── prototype-project/
```

## This can include

- design documents
- system notes
- mechanics ideas
- UI and menu concepts
- playable prototypes
- game pitch docs

## Rule

Each game has its own folder and its own direction, even if they all belong to the same world. That keeps the ideas clear and separate.
