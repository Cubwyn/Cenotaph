# Cenotaph game

This directory is the main creative project area for Cenotaph: The Great Omission and related game work.

It is intentionally separate from the repository's learning, documentation, and tooling areas so the main game can evolve without being drowned out by supporting work.

## Contents

- `design/` for design notes and high-level creative direction
- `prototypes/` for small isolated experiments and testable building blocks
- `notes/` for game-specific observations, ideas, and unresolved questions
- `archive/` for older or superseded material that should be preserved but not treated as active direction

## Relationship to the rest of the repo

The game should remain the main creative center of the project, but it should not absorb every experiment or supporting document without explicit intent.
