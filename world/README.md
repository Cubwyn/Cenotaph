# World directory

This is where the setting lives.

The world is the bigger thing. The projects are smaller expressions of it.

## Structure

```text
world/
├── README.md
└── projects/
    ├── project-one/
    └── project-two/
```

## What belongs here

- geography
- factions and powers
- important locations
- myth, history, and magical systems
- world notes that shape the setting

## Important rule

The world folder is not a single project. It is the shared background that different projects can draw from.

Each project under `world/projects/` can still have its own identity and its own notes.
