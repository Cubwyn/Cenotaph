# Shared world files

This is the part of the repository for big, broad pieces of the setting that can support multiple projects at once.

Think of it as the quiet backbone of the world.

## What goes here

- established lore
- world history
- broad references and inspiration
- timeline notes
- major setting truths that multiple projects can rely on

## Typical folders

- `canon/` for the facts that feel stable
- `references/` for art and inspiration
- `timeline/` for major events and eras

## Rule

This folder should be useful and easy to reference, but it should not become a dump of everything from every project.

Shared material should help the world feel coherent, not bury it in clutter.
