# Text archive

This is where the writing lives.

Stories, scenes, journals, character voices, and anything prose-based can live here.

## Structure

```text
text/
├── README.md
└── projects/
    ├── story-one/
    ├── story-two/
    └── journal-project/
```

## Good things to put here

- short stories
- chapters or scenes
- letters, journals, and logs
- character voice and dialogue pieces
- narrative experiments

## Rule

Keep each writing project in its own folder. Don’t lump unrelated stories together just because they share the same setting.
