# Toolchain

This directory is for the software development and engine-related work that supports Cenotaph but does not automatically define the game itself.

It is intentionally separated from the main game so tooling experiments can evolve independently.

## Contents

- `engine/` for engine or core runtime experiments
- `editor/` for editor tooling and project infrastructure
- `experiments/` for smaller, more disposable technical tests

## Relationship to game

This is a supporting project area, not automatically the canonical architecture of the game.
